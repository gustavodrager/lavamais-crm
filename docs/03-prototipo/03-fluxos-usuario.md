# Fluxos de Usuário

> Status: historico e substituido. Os fluxos dependentes de movimentacoes e Cliente 360 pertencem ao roadmap.

## Fluxo 1 — Atendimento personalizado

```text
Cliente chama no WhatsApp
↓
Atendente busca cliente no sistema
↓
Abre Perfil 360°
↓
Visualiza alertas, preferências e histórico
↓
Responde o cliente com mais contexto
↓
Registra nova interação
↓
Se necessário, cria próxima ação
```

## Fluxo 2 — Recuperação de cliente inativo

```text
Usuário entra na Central de Relacionamento
↓
Vê oportunidade: clientes inativos
↓
Abre lista de clientes sem movimento há 30 dias
↓
Escolhe cliente
↓
Abre Perfil 360°
↓
Confere contexto
↓
Envia WhatsApp com template personalizado
↓
Sistema registra notificação
↓
Cliente responde
↓
Usuário registra interação
↓
Se o cliente compra novamente, vira recuperado
```

## Fluxo 3 — Campanha comercial

```text
Gerente cria campanha
↓
Define segmento
↓
Escolhe template
↓
Sistema lista clientes elegíveis
↓
Usuário envia WhatsApp individualmente
↓
Cada envio fica registrado
↓
Usuário registra respostas
↓
Sistema mede resultado
```

## Fluxo 4 — Cliente VIP sem contato recente

```text
Sistema identifica cliente VIP sem contato há 15 dias
↓
Cria oportunidade na Central de Relacionamento
↓
Gerente abre o cliente
↓
Consulta histórico e preferências
↓
Envia mensagem personalizada
↓
Registra interação
↓
Marca oportunidade como resolvida
```

## Fluxo 5 — Aniversariante

```text
Sistema identifica aniversariante do dia
↓
Cria oportunidade
↓
Usuário escolhe template de aniversário
↓
Abre WhatsApp
↓
Registra envio
↓
Cliente responde
↓
Usuário registra interação
```
